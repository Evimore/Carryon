# Known system folders: Carryon never suggests backing these up when it looks for new data in
# /var/lib, /var/opt and /srv. They hold the system's own state, which a fresh install makes
# again (package databases, caches, machine-specific runtime state), or data another part of the
# record already covers (Flatpak apps, Bluetooth pairings).
#
# One absolute path per line; shell patterns (*, ?, [...]) match one path component each.
# A folder inside a listed one isn't suggested either. Contributions welcome: see catalog/README.md.
